My first project: a University Management System in C++

File handling, structures and a console. Still useful to remember.

Date
December 2014

Where

Every engineer has a first project. Mine was a University Management System in C++, a first-semester project built on file handling.

What it did

It managed university-style records from a console program. There was no database and no framework, just structures, functions and files read and written by hand.

What it taught me

  • Data has to live somewhere. Writing and reading files makes you think about formats, ordering and what happens when a file is half-written.
  • Small functions with clear jobs make a program you can still understand a month later.
  • Debugging is the actual work.

Why I still mention it

Nearly everything I build now sits on layers someone else wrote. Knowing what is underneath, a file, a record, a loop, keeps me honest about what the layers are doing for me.
